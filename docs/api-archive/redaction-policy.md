# Redaction policy

아카이브에는 재사용 가능한 구조만 남기고 실제 세션이나 개인 데이터는 남기지
않는다.

## 절대 저장하지 않는 값

- `MoodleSession`, `MOODLEID*` 및 모든 `Cookie`/`Set-Cookie` 값
- `sesskey`, `logintoken`, CSRF 토큰, 서명값, 일회용 URL
- 아이디, 학번, 비밀번호, 이름, 이메일, 전화번호
- 최종 접속 IP와 접속 시각 등 계정 활동 정보
- 실제 강좌 가입 상태, 과제·성적·메시지·알림 내용
- GA, Clarity, Mixpanel 등 분석 식별자

## 저장 가능한 형태

- 파라미터 **이름**은 저장할 수 있다. 예: `year`, `semester`, `sesskey`.
- 민감 값 예시는 `${REDACTED}` 또는 타입 설명으로 대체한다.
- HTML 원문 대신 selector와 필드 의미를 요약한다.
- 강좌 fixture는 실제 수강정보가 아닌 명백한 합성값을 사용한다.
- 응답 헤더는 콘텐츠 형식 등 필요한 항목만 남기고 쿠키·식별 헤더는 제거한다.

## 수집 안전 규칙

- 자동 탐색은 GET/HEAD만 사용한다.
- 로그인 POST는 사용자가 그 시점에 명시적으로 허용한 경우에만 수행한다.
- 확장 프로그램 런타임의 유일한 비로그인 POST 예외는 사용자가 알림 패널에서
  새로고침을 직접 누른 경우의 고정된 `coursemostype=lists` 조회다. 자동 탐색은
  이 예외도 호출하지 않는다.
- 글쓰기·댓글·메시지 발송, 파일 업로드, 알림 삭제, 수강 신청·취소, 설정 변경을
  포함한 그 밖의 POST/PUT/PATCH/DELETE 요청은 문서화만 하고 호출하지 않는다.
- `safeToProbe: false`는 메서드가 GET이어도 개인정보 노출이나 상태 변경 가능성이
  있음을 뜻한다.
- 인증된 원문 파일은 이 저장소에 복사하지 않는다.
